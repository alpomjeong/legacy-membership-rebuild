# 네이티브 앱 빌드 가이드 (Expo / EAS)

화면·기능은 완성돼 있고, 이제 **실기기 테스트 → 네이티브 빌드**만 하면 된다.
**안드로이드는 계정 없이** 테스트/설치할 수 있고, **iOS 는 나중에** Apple 개발자 계정이 준비되면 진행한다.

> ⚠️ 중요:
> - **API 주소(`EXPO_PUBLIC_API_BASE`)는 절대 URL**이어야 한다(네이티브 fetch 는 상대경로 불가).
> - **포트 8080** = 네이티브 서버 단일 포트(`infra\native\start.bat`, API+pc-web). 배포는 8080 이 맞다.
>   (백엔드를 `pnpm start:dev` 로 단독 실행할 때만 3000.)
> - **cleartext(http)**: Android **release APK·iOS 는 http 차단**. 아래 "빠른 테스트"만 http LAN 허용.

## 1. 가장 빠른 테스트 — Expo Go (계정·빌드 0)
같은 와이파이에서 서버(`infra\native\start.bat`)가 떠 있을 때:
```bash
cd mobile
# 서버 PC 의 LAN IP 로 지정(ipconfig 로 확인)
set EXPO_PUBLIC_API_BASE=http://<서버-IP>:8080/api/v1   # PowerShell: $env:EXPO_PUBLIC_API_BASE="..."
npx expo start
```
폰에 **Expo Go** 앱 설치 → 터미널 QR 스캔 → 앱 실행. (Expo Go 는 개발 모드라 LAN http 접속 허용)

## 2. 설치형 APK (안드로이드, 계정 없이 사이드로드)
release APK 는 **http 차단**이라 **https 주소가 필요**하다(도메인+터널 준비 후, `운영-배포-가이드.md` 3단계).
```bash
# eas.json 의 preview 프로필 EXPO_PUBLIC_API_BASE 를 https 서버주소로 먼저 수정
npm i -g eas-cli && eas login          # 무료 Expo 계정(개발자 계정 아님)
eas build --profile preview --platform android
```
→ 클라우드 빌드 후 **APK 링크** 제공 → 폰에 설치. Google Play 정식 등록은 나중에(개발자 계정 $25, `production` 프로필).

> http LAN 으로 "설치형"까지 당장 테스트하려면 `development` 프로필(dev-client, 디버그 변형이라 cleartext 허용)을 쓰거나, 위 1번(Expo Go)을 쓴다.

## 3. iOS (나중에 — Apple 개발자 계정 필요, https 필수)
```bash
eas build --profile production --platform ios
```
- **Apple 개발자 프로그램(연 $99)** + https 주소 필요(ATS). 시뮬레이터 테스트(Mac)는 무료.

## 4. 순서 요약
1. **Expo Go** 로 LAN 테스트(계정 0) → 동작 확인
2. 도메인+터널(https) 준비 → `eas.json` 의 `EXPO_PUBLIC_API_BASE` 를 https 로 수정
3. `preview` 로 안드로이드 APK 빌드 → 설치 배포
4. (도메인+개발자계정) `production` 빌드 → 스토어 제출
5. (별도) 기일 알림 푸시

## 참고
- 번들 ID: iOS/Android 모두 `com.bulsa.member` (app.json).
- `eas.json` 의 `REPLACE-WITH-...` 는 플레이스홀더 — **빌드 전 실제 서버 주소로 반드시 교체**.
