# 📱 폰 앱 만들기 / 테스트 가이드

도메인 없이 **같은 와이파이**에서 폰에 앱을 올려 테스트하는 방법입니다.
(앱을 실제로 빌드하려면 무료 **Expo 계정**이 필요해요 — https://expo.dev 가입)

---

## 방법 A. 지금 바로 테스트 (빌드 없이, 5분)

폰에 **Expo Go** 앱 설치(플레이스토어/앱스토어) → 같은 와이파이에서 미리보기.

1. 이 PC에서 서버가 켜져 있어야 함(도커 스택 실행 중).
2. 터미널에서:
   ```
   cd mobile
   npx expo start
   ```
3. 터미널에 뜬 **QR 코드**를 폰 카메라(또는 Expo Go)로 스캔.
4. 앱이 폰에서 열림. 로그인해서 사용.

> 서버 주소는 `mobile/.env` 또는 실행 시 `EXPO_PUBLIC_API_BASE=http://<개발-PC-IP>:8081/api/v1 npx expo start` 로 지정.
> Expo Go 는 개발/시연용 — 진짜 설치 앱은 방법 B.

---

## 방법 B. 진짜 설치되는 앱(APK) 만들기 (Expo 클라우드 빌드)

한 번만 준비:
```
npm install -g eas-cli      # EAS 명령어 설치
cd mobile
eas login                   # Expo 계정 로그인(대화형 — 직접 입력 필요)
eas init                    # 이 앱을 내 Expo 계정에 연결(projectId 생성)
```

안드로이드 APK(설치 파일) 만들기:
```
eas build -p android --profile development
```
- 클라우드에서 10~15분 빌드 → 완료되면 **다운로드 링크(APK)** 를 줌.
- 그 링크를 폰에서 열어 설치(“출처를 알 수 없는 앱” 허용 필요).
- 이 개발 프로필은 **같은 와이파이의 이 PC(http://<개발-PC-IP>:8081)** 에 접속하도록 설정돼 있음.

아이폰(iOS)은 Apple 개발자 계정($99/년)이 있어야 실기기 설치가 됩니다. 안드로이드부터 권장.

---

## 나중에 (도메인/HTTPS 생기면)

1. `eas.json` 의 `preview`·`production` 프로필의 `EXPO_PUBLIC_API_BASE` 를 실제 HTTPS 주소로 교체.
2. 배포용 빌드: `eas build -p android --profile production` → 구글 플레이 업로드.
3. iOS: `eas build -p ios --profile production` → 앱스토어(Apple 개발자 계정 필요).

---

## 아직 남은 것(앱 기능)

- **푸시 알림 수신**: 서버(기일 알림)는 준비됐지만, **폰 앱에서 알림 토큰을 등록/수신하는 코드는 아직 없음**
  (`expo-notifications` 도입 + 권한 요청 + 토큰 등록 필요). 알림까지 쓰려면 이 작업이 추가로 필요합니다.
